# Contributor License Agreement

**Authoritative CLA:** https://docs.solved.gg/legal/2026-07-04/cla

## Enforcement

Pull requests are gated by the **CLA Assistant** GitHub Action
(`.github/workflows/cla.yml`). External contributors must reply on the PR with:

```
I have read the CLA Document and I hereby sign the CLA
```

Signatures are stored in [`signatures/cla.json`](signatures/cla.json).
Comment `recheck` to re-run the check.

Corporate / offline CLA: [intake@solved.gg](mailto:intake@solved.gg).

**No CLA, no merge** for external contributions.

## Dual-class outbound licensing

This CLA enables iResolved, LLC to distribute contributions under the dual-class
model (Class A source-available `LICENSE.md` + Class B [EULA](https://docs.solved.gg/legal/2026-07-04/eula)).
